# Refis

Локальное приложение для хранения и поиска референсов, своих работ и видеоуроков для рисования.
Работает без интернета. Файлы остаются в ваших папках: Refis их не копирует и не перемещает,
а строит каталог с превью, тегами, оценками и заметками.

## Установка (Windows 11)

1. Установите **Python 3.12 или 3.13** с [python.org](https://www.python.org/downloads/).
   В установщике отметьте галочку **«Add python.exe to PATH»**.
2. Скачайте этот репозиторий (Code → Download ZIP) и распакуйте в любую папку,
   например `D:\Refis`.
3. Дважды щёлкните **`Refis.bat`**. Первый запуск займёт пару минут: скачаются нужные компоненты.
   Дальше приложение открывается за секунду.

Если окно не открылось, запустите **`Refis (в браузере).bat`**: интерфейс откроется в браузере,
а в чёрном окне будут видны сообщения об ошибках.

Каталог, превью и журнал хранятся в папке `data` рядом с приложением.
Чтобы сделать резервную копию тегов и заметок, достаточно скопировать файл `data\refis.db`.

## Что умеет

- **Папки библиотеки.** Добавьте, например, «Референсы» и «Мои арты» и укажите, что в каждой лежит
  по умолчанию (референсы, свои работы, туториалы). Названия подпапок можно сразу превратить в теги.
  При каждом запуске папки пересканируются: новые файлы появляются сами.
- **Теги.** Ставьте их на один файл или сразу на много (Ctrl/Shift + клик).
  Вложенность задаётся через `/`, например `анатомия/руки`: поиск по `анатомия` найдёт и вложенные теги.
  Теги можно переименовывать и объединять (ПКМ по тегу).
- **Поиск.** Строка поиска понимает слова (имя, заметки, источник, путь), `#тег`, `-#тег` (исключить)
  и `-слово`. В боковой панели клик по тегу включает его в фильтр, Alt+клик исключает.
  Есть фильтры по типу, ориентации и рейтингу, сортировка (в том числе случайная).
  Нужные подборки можно сохранить кнопкой **☆ Сохранить**.
- **Разделы:** избранное, файлы без тегов (удобно разбирать хаос), дубликаты,
  пропавшие файлы (удалённые или перемещённые).
- **Просмотр.** Зум колесом, перетаскивание, зеркало (H), ч/б (G), размытие для тонального разбора (B).
  Для видео: покадровая перемотка (`,` и `.`), скорость от 0.1× до 2× (`[` и `]`), повтор,
  Shift+стрелки перематывают на ±5 секунд.
- **Тренировка набросков.** Таймер по картинкам из текущей подборки или из выбранных файлов:
  30 сек, 1, 2, 5 или 10 минут, свои значения или без таймера.
- **Добавление файлов.** Перетащите картинки или видео в окно: они скопируются в выбранную папку
  библиотеки (по умолчанию в подпапку `_Входящие`) с указанными тегами.
- **Показать в проводнике** и **Открыть в программе** (например, видео в формате, который
  не играет встроенный плеер).

## Горячие клавиши

| Где | Клавиша | Действие |
|---|---|---|
| Сетка | Двойной клик / Enter | Открыть просмотр |
| Сетка | Ctrl+A, Esc | Выбрать всё / снять выбор |
| Сетка | Ctrl+F или `/` | Перейти к поиску |
| Просмотр | ← → | Предыдущий / следующий |
| Просмотр | H, G, B, 0 | Зеркало, ч/б, размытие, вписать |
| Просмотр | F | В избранное |
| Видео | Пробел, `,` `.`, `[` `]`, L | Пауза, кадр, скорость, повтор |
| Тренировка | Пробел, ← →, Esc | Пауза, листать, закончить |

## Форматы

Картинки: jpg, png, gif, webp, bmp, tiff, psd.
Видео: mp4, webm, mov, m4v, mkv, avi, wmv, flv, mpg. Встроенный плеер воспроизводит mp4, webm, mov и mkv
с распространёнными кодеками. Остальное открывается кнопкой «Открыть в программе».

## Для разработки

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python -m refis            # окно приложения
.venv\Scripts\python -m refis --browser  # в браузере
```

Устройство: `refis/server.py` (FastAPI, HTTP API), `refis/media.py` (сканирование, превью через
Pillow и ffmpeg), `refis/db.py` (SQLite), `refis/static/` (интерфейс без сборки: HTML, CSS, JS).
Окно рисует pywebview поверх встроенного в Windows движка Edge (WebView2).
Переменные окружения: `REFIS_DATA` (папка данных), `REFIS_PORT` (порт).
