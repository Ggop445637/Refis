# Refis

Локальное приложение для хранения, поиска и изучения референсов, своих работ и видеоуроков для рисования.
Работает без интернета. Файлы остаются в ваших папках: Refis их не копирует и не перемещает,
а строит каталог с превью, тегами, оценками и заметками.

## Установка (Windows 10/11)

### Вариант 1 — установщик `.exe` (рекомендуется)

1. Откройте вкладку **Actions** репозитория → последний успешный запуск **«Сборка Refis для Windows»**
   → внизу в **Artifacts** скачайте `Refis-…-windows` (или возьмите файлы из раздела **Releases**, если там есть версия).
2. Распакуйте и запустите **`Refis-Setup-….exe`**. Права администратора не нужны: появятся ярлыки
   в меню «Пуск» и на рабочем столе, удаление — через «Параметры → Приложения».
   Данные хранятся в `%LOCALAPPDATA%\Refis`.

Есть и **портативная версия** `Refis-portable-….zip`: распакуйте куда угодно (хоть на флешку)
и запустите `Refis.exe`. Данные лежат в папке `data` рядом с программой.

> Если Windows SmartScreen предупредит о неизвестном издателе — «Подробнее» → «Выполнить в любом случае».
> Программа не подписана сертификатом, это нормально для личных проектов.

**Перенос данных со старой версии** (запуск через `Refis.bat`): скопируйте содержимое старой папки `data`
в `%LOCALAPPDATA%\Refis` (или в `data` рядом с портативным `Refis.exe`).

### Вариант 2 — из исходников

1. Установите Python 3.12 или 3.13 с [python.org](https://www.python.org/downloads/), отметив «Add python.exe to PATH».
2. Скачайте репозиторий (Code → Download ZIP), распакуйте и запустите **`Refis.bat`**.

## Что умеет

**Сегодня** — стартовый экран:
- **Референс дня** — новая картинка из вашей библиотеки каждый день, кнопка «Рисовать 10 мин».
- **Нарисуй это** — генератор заданий: тема (в том числе из ваших тегов), условие освещения или ракурса,
  ограничение («только 3 тона», «одной линией»…) и время. Можно со случайным референсом.
- Статистика, **серия дней практики** 🔥, календарь занятий за 16 недель, недавно добавленное,
  «давно не открывали» и облако ваших тем.

**Библиотека:**
- Раскладка **плиткой без обрезки** или квадратами, плавные анимации, превью видео при наведении.
- Поиск: слова, `#тег`, `-#тег`, `-слово`; фильтры по типу, форме, оценке; сохранённые поиски.
- Вложенные теги (`анатомия/руки`), переименование и слияние тегов, теги из названий папок.
- Выделение рамкой мышью, Ctrl/Shift+клик, массовое редактирование с **отменой** снятия тегов.
- **Палитра** каждой картинки — клик по цвету копирует HEX.
- Разделы «Без тегов», «Дубликаты», «Пропавшие» — чтобы разобрать хаос.
- Добавление: перетащите файлы в окно или **вставьте картинку из буфера** (Ctrl+V) — например, скопированную в браузере.
- **Ctrl+C** копирует картинку — сразу вставляйте в Photoshop, Krita, Clip Studio.

**Просмотр:** открывается анимацией из карточки; зум к курсору, зеркало, ч/б, размытие для тонов,
**сетка пропорций** 3×3/4×4, поворот, **пипетка**, палитра. Для видео — покадровая перемотка, скорость 0.1–2×, повтор.

**Доски** (как PureRef): бесконечный холст, картинки из библиотеки, файлов или буфера обмена, видео, заметки
разных цветов; перемещение, масштаб, зеркало, ч/б, слои, «Упорядочить», отмена (Ctrl+Z), экспорт в PNG
(в «Изображения\Refis»), режим **«Поверх всех окон»** — доска висит рядом с вашим редактором.

**Тренировка:** наброски с таймером по любой подборке, отсчёт 3-2-1, круговой таймер, журнал практики.

**Командная панель** — `Ctrl+K`: быстрый переход к любому тегу, доске, поиску или действию.

## Горячие клавиши

| Где | Клавиши | Действие |
|---|---|---|
| Везде | Ctrl+K | Командная панель |
| Везде | Ctrl+1 / 2 / 3 | Сегодня / Библиотека / Доски |
| Везде | Ctrl+F или `/` | Поиск |
| Библиотека | Стрелки, Shift+стрелки | Перемещение и выделение |
| Библиотека | Пробел / Enter | Открыть просмотр |
| Библиотека | 1–5, 0 | Оценка / сброс |
| Библиотека | F, T, I | Избранное, добавить тег, панель деталей |
| Библиотека | Ctrl+A, Ctrl+C, Ctrl+V | Выделить всё, копировать, вставить |
| Просмотр | ← →, Пробел | Листать |
| Просмотр | H, G, B, S, R | Зеркало, ч/б, размытие, сетка, поворот |
| Просмотр | I, F, 0, двойной клик | Пипетка, избранное, вписать, зум |
| Видео | Пробел, `,` `.`, `[` `]`, L, M | Пауза, кадр, скорость, повтор, звук |
| Доска | Колесо, тянуть фон, Shift+тянуть | Зум, сдвиг, выделение |
| Доска | H, G, `]` `[`, Delete | Зеркало, ч/б, слои, удалить |
| Доска | Ctrl+D, Ctrl+Z, A, F, N | Копия, отмена, упорядочить, показать всё, заметка |
| Тренировка | Пробел, ← →, Esc | Пауза, листать, закончить |

## Сборка .exe самостоятельно

На Windows:

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt pyinstaller
.venv\Scripts\python tools\build_exe.py        → dist\Refis\Refis.exe
iscc installer\refis.iss                       → dist\Refis-Setup-2.0.0.exe (нужен Inno Setup 6)
```

Новый релиз с файлами в Releases: создайте тег `v2.0.1` и отправьте его в GitHub — сборка запустится сама.
Иконку можно перерисовать скриптом `tools/make_icon.py`.

## Устройство

- `refis/server.py` — HTTP API (FastAPI), `refis/media.py` — сканирование и превью (Pillow, ffmpeg),
  `refis/db.py` — SQLite с автоматическими миграциями.
- `refis/static/` — интерфейс без сборки (ES-модули): `js/library.js`, `viewer.js`, `boards.js`,
  `practice.js`, `today.js`, `main.js`; стили и анимации — `css/style.css`.
- Окно — pywebview поверх встроенного в Windows движка Edge (WebView2).
- Переменные окружения: `REFIS_DATA` (папка данных), `REFIS_PORT` (порт). Флаги: `--browser`, `--selftest`.
